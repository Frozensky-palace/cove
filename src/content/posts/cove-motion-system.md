Cove 的动效不是设计出来的，是修出来的。这篇复盘按时间线讲：动效边界怎么定、三个真实的时序 bug、以及最后如何用两条缓动令牌把全站收口。

## 先定边界：什么才配动

动效指南只有一条原则：**动效必须有信息含义**。落成白名单就是：

- 颜色与透明度过渡（悬停、状态切换），120–220ms；
- 位移不超过 2px（上浮、下沉的暗示），同档时长；
- 折叠展开（目录、系列列表）——高度变化本身即信息；
- 一次性动效可以放宽：入场上浮 560ms、主题切换的圆形揭示 450ms，但绝不允许循环动画装饰页面。

所有动效统一受 `prefers-reduced-motion` 全局规则约束——一条把全部 animation/transition 时长压到 0.01ms 的规则，任何新动效自动被覆盖，不需要逐个分支处理。这条规则是动效系统的第一块基石：**可关闭性由结构保证，而不是靠自觉**。

## 坑一：从未生效的淡出

加载页的退场动画做了之后很久，我才发现它从未生效过——加载页一直是以硬切方式消失的。

根因是时序：`dismiss()` 在添加淡出类**之前**先移除了控制 `display` 的标记。`display` 同帧回到 `none`，元素直接从渲染树消失，`opacity` 过渡从未获得渲染机会。修复方式是把顺序反过来：保持 `display: grid`，先播 200ms 淡出，240ms 后再移除节点。

同一周还踩了它的姊妹坑：入场动画用 `animation-fill-mode: both` 填充，已结束的动画把 `opacity/transform` 驻留在元素上，以更高优先级压住了退场的同名 transition——入场动画"钉住"了退场动画。改成 `backwards` 填充（只填充延迟期，不驻留结束态）才解开。

这两个坑给了我一条经验：**CSS 动效的 bug 极少出在动画本身，几乎全出在 display、opacity、transition 三者的相遇时机**。凡是"动画偶尔不播"的问题，先查 `display` 有没有同帧切换。

## 坑二：换页之后世界被重置

引入客户端路由（ClientRouter）后，换页是把 `<html>` 属性整体覆盖回服务端渲染态。于是三个回归同时出现：深色主题被重置回浅色、`no-js` 类残留导致搜索入口重复、加载页在本地静态页上不可见。

修复的思路分两层：换页后需要存活的逻辑（主题恢复、事件委托）挂到 `astro:page-load` / `astro:after-swap` 事件上，用监听器跨换页存活；而"仅无 JS 时存在"的东西（搜索回退链接）直接搬进 `<noscript>`——有 JS 就不进渲染树，从语义上退出竞争，连 CSS 都不用写。这比之前"始终渲染 + CSS 按类切换"的方案少了一整类特异性冲突。

## 坑三：特异性战争没有赢家

搜索回退链接隐藏失效的完整诊断让我彻底放弃用 CSS 打 hide-and-seek：组件 scoped 规则 `.search-entry[data-astro-cid]`（特异性 0,2,0）恒压过全局 `.search-fallback { display: none }`（0,1,0），回退链接在任何有 JS 的环境下从未被隐藏过——之前的"修复"只是不断给全局规则加戏。

`<noscript>` 方案一行 CSS 就解决了。教训：**当你在和特异性搏斗时，正确答案通常是换一种语义机制，而不是继续加选择器**。

## 收口：两条缓动令牌

动效数量过十之后，`cubic-bezier(0.4, 0, 0.2, 1)` 这样的字面量开始散落在各处。收口成两条令牌：

```css
:root {
  /* 小变化：颜色、边框、状态切换 */
  --ease-standard: cubic-bezier(0.4, 0, 0.2, 1);
  /* 入场与大位移：减速收尾 */
  --ease-out: cubic-bezier(0.22, 1, 0.36, 1);
}
```

归则很简单：小变化用 standard，入场和大位移用 out。归完之后全站动效只剩三个自由度：时长、位移量、选哪条曲线。

最后一个案例是首页的"值守者百叶窗"（三块角色面板，悬停展开）。它最终参数是展开 850ms 带过冲、收拢 180ms 干脆利落——时长比接近 5:1。速度感知主要来自这个比例和约 12% 的过冲幅度，而不是任何单一参数的绝对值。简介文字延迟 200ms 浮出，等面板展开过半再入场；简介用绝对定位浮层而不是占位元素，避免文字换行数不同把三块面板的底边顶得高低不一。

## 小结

| 原则 | 落地 |
| --- | --- |
| 动效要有含义 | 白名单：颜色 / ≤2px 位移 / 折叠 / 一次性 |
| 必须可关闭 | `prefers-reduced-motion` 全局规则，结构保证 |
| 时长即语言 | 一慢一快成对出现（展开 850ms / 收拢 180ms） |
| 参数令牌化 | 两条缓动曲线，三个自由度 |

动效系统化真正的产出不是那几条曲线，而是**决策成本的消失**：现在加一个新动效，不需要开会讨论感觉，只需要对照白名单和令牌。这才是"系统"两个字的含义。
