# Phase 8.1 手动复验清单

Phase 8.1「页面优化」（IMPL-056–072）代码侧整改已合并 `main`。各 IMPL 条目标注的
**浏览器复验项**汇总于此，全部通过后 Phase 8.1 关闭。各项依据以
[`decision-log.md`](../decision-log.md) 对应条目为准（评审报告为当时快照）。

---

## 0. 环境与通用操作

- 启动：`pnpm build && pnpm preview`（本地验收）。**搜索结果相关项必须在 preview 下
  验**——`pnpm dev` 没有 Pagefind 索引，只能看到空态。
- 每一项浅色 / 深色主题各看一遍，除非条目另有说明。
- 复看 Splash：DevTools → Application → Session Storage → 删除 `cove:splash-shown`
  → 刷新首页（每会话仅首访播放）。
- 模拟减少动效：DevTools → Rendering → Emulate CSS media feature
  `prefers-reduced-motion: reduce`。
- 触控项（44px、软键盘）优先真机；DevTools 设备工具栏仅作初筛。

## 1. 搜索（IMPL-059 F01/F03–F06、IMPL-062 L03）

- [ ] ① **跨页生命周期**：连续站内软导航换页约 10 次后，页头搜索入口仍能打开弹窗，无旧实例残留、无重复监听（快速点开关闭多次也不卡）；
- [ ] ② **懒加载边界**：未用过搜索的页面上，搜索入口是指向 `/search/` 的普通链接（Network 不预载 Vue chunk）；首次点击后弹窗打开，此后换页各页均直接可用；
- [ ] ③ **全结果分页**：用宽泛词（如「的」）搜出 12 条以上 → 完整搜索页出现「加载更多」，逐次加载直到「已显示 N 条（全部）」；弹窗保留第一页 + 「在完整搜索页查看全部 N 条」链接，跳转后关键词与筛选保持；
- [ ] ④ **竞态与输入法**：快速输入 A→B 不出现与当前词不符的结果；加载窗口内按回车不跳转；真实中文输入法选词过程中方向键 / 回车不抢占、不误跳转；
- [ ] ⑤ **URL 恢复**：搜索页带 `?q=…&type=…` 刷新后状态一致；缺省 / 非法 type 回默认值；浏览器前进后退状态跟随；URL 上 hash 不丢失；
- [ ] ⑥ **结果行小屏**：<480px 时日期换到标题次行；长标题 / 英文长词不撑破列、无横向滚动；
- [ ] ⑦ **触控目标**：真机或 `(pointer: coarse)` 模拟下，筛选按钮高 44px 且间距足够。

## 2. 搜索与弹窗的失败恢复（IMPL-059 F04、D08）

- [ ] ① DevTools Network 拦截 `/pagefind/*` 后搜索：完整页出现读者向错误提示（含重试 + 分类浏览出口），恢复网络后点重试能真正重新加载；
- [ ] ② 拦截搜索弹窗的 Vue chunk 后点击搜索入口：放行原生导航到 `/search/`，不吞点击；
- [ ] ③ 禁 JS（或只阻断 Vue 分片）浏览：核心导航、文章阅读、页头搜索普通链接仍可用。

## 3. 评论（IMPL-059 F02）

- [ ] ① Network 拦截 giscus 脚本 → 文章页评论区约 10 秒后出现失败占位 + 重试按钮 + 邮件直达入口；
- [ ] ② 点重试：旧脚本 / 旧 iframe 被清除后重新注入，成功后只有一个 giscus 框、能正常发评论；
- [ ] ③ 评论区可见时切换站点主题 → 评论区跟随变色；换页后新页面评论区主题仍跟随；
- [ ] ④ 评论 host 脱离文档（换页离开）后不再无限轮询（Performance 面板无持续 activity 即可）。

## 4. Splash 加载页（IMPL-062 M01、IMPL-066、IMPL-068/070）

- [ ] ① **三态**：首页会话首访播放；会话内直接深链文章页（新开窗口进文章 URL）不播且之后回首页也不补播；`prefers-reduced-motion: reduce` 下直接显示内容、零等待；
- [ ] ② **退场时序**：展示不少于约 1.6s（能看到完整品牌组），页面就绪后 200ms 淡出，无拦腰截断的闪烁；
- [ ] ③ **设计观感（双主题各一次首访）**：极光光晕（左上蓝 / 右下粉）+ 颗粒噪点 + 品牌组背后光晕的浓度可接受；无海面带（已删）；深色下发闷与否；
- [ ] ④ **错峰入场**：标志 → 字标 → 环境层 → 标语依次浮现，节奏自然；深色下标志渐变与「Cove」渐变字标对比清晰。

## 5. 首页与窄屏首屏（IMPL-062 L01/M02、视觉评审第 8 节补测宽度）

- [ ] ① **320×568**：页头单行；Hero 收敛后首屏内能看到文章入口（首卡不被完全挤出）；无横向滚动；
- [ ] ② **375px**：首卡位置、标题换行、插画比例正常；补看 768 / 1440px 无跳变；
- [ ] ③ **插画动效**：首页插画无常驻上下漂浮，仅保留一次性入场与 hover 反馈；
- [ ] ④ **断点临界**（L04）：767/768、899/900、959/960、1279/1280 各两侧各看一次，布局无横向溢出、无怪异跳变。

## 6. 对比度与状态色（IMPL-061 V01/V02）

- [ ] ① 浅色主题抽查摘要、日期、标签、页脚、搜索提示等 `--text-muted` 小字：白卡 / 页面底 / 浅灰蓝面三种底色上均清晰可读；
- [ ] ② 项目卡与项目详情「已完成」粉色状态文字（浅 / 深）清晰可辨，与装饰粉描边层次分明。

## 7. 键盘焦点与整卡反馈（IMPL-064 V04）

- [ ] Tab 遍历首页（精选 / 最新 / 笔记 / 项目）、文章列表、项目列表、系列详情页：键盘聚焦卡内链接时**整卡**出现与 hover 同款反馈（上浮描边或整行淡底），且链接自身焦点环可见；鼠标点击链接后不残留悬挂反馈。

## 8. 项目详情与关于页（IMPL-060/V03、IMPL-061 L02、IMPL-067）

- [ ] ① 项目详情：封面显示正常（有 / 无封面各一）；操作按钮行为 44px 药丸样式，`label` 与类型同字时（现有「源码」）只渲染一个标签不重复；
- [ ] ② **横屏抽屉**（667×375 或真机横屏）：打开移动抽屉可纵向滚动，「隐私 / RSS」等底部入口可达，关闭按钮始终可见；
- [ ] ③ **值守者百叶窗**：悬停展开约 1.6s 的慢速节奏、末段轻微过冲回落自然；移开后约 0.6s 收拢；简介延后浮现不抢拍。

## 9. 动效节奏总览（IMPL-065 M03）

- [ ] 正常动效模式下走一遍主要交互（卡片悬停、弹窗 / 抽屉开合、页面淡入、主题切换、单次入场）：小反馈 / 浮层 / 重点动效三档节奏统一，无某个交互明显过快或过慢；评审第 8 节要求录制对比的可选做。

## 10. 线上抽查（`main` 已部署 cove.xin）

- [ ] ① 线上搜索（生产索引）随机 2–3 个真实关键词出正确结果，结果行布局与本第 1 节一致；
- [ ] ② 线上打开任一文章 / 项目 / 值守者页 → 分享预览 OG 图为 1200×630 品牌卡（IMPL-056 动态生成项的线上核对）；
- [ ] ③ README（GitHub 端）头图、徽章、站点入口与文档链接渲染正常（IMPL-072）。
